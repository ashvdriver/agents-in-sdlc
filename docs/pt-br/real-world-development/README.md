Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar comportamentos, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é uma nova pessoa desenvolvedora da Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com tema de desenvolvimento. O backlog da sua equipe já está registrado como issues do GitHub, pronto para você começar. Ele inclui trabalho de novos recursos, como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot acompanha você onde quer que trabalhe. Escolha o ambiente que corresponde à forma como você quer desenvolver. Cada workshop começa com a própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no seu terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, MCP do Playwright, Agent Merge e comandos de barra práticos.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agente em paralelo, alterne entre modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho dele, acompanhe o progresso e revise os pull requests que ele abre.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e nos GitHub Codespaces. Trabalhe com o modo agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
