通过真实场景、完整的应用程序和共享待办事项，探索软件开发生命周期中的 GitHub Copilot。你将以迭代方式规划更改、创建代码、测试行为、审查拉取请求，并借助智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构的公司，为开发者主题的桌游提供众筹服务。团队的待办事项已作为 GitHub 议题提交，可供你认领。其中既有筛选和分页等功能工作，也有辅助功能和编码标准等质量改进。

## 选择环境

GitHub Copilot 可以融入你的工作环境。请选择符合你构建方式的环境。每个工作坊都从各自的设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

使用终端中的智能体助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 以及实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、在画布上协作，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
