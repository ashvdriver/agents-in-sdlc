Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y una lista de trabajo pendiente compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un desarrollador nuevo en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. La lista de trabajo pendiente de tu equipo ya está registrada como incidencias de GitHub, lista para que la retomes. Incluye trabajo de funcionalidades, como el filtrado y la paginación, junto con mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña allí donde trabajes. Elige el entorno que mejor se ajuste a tu forma de desarrollar. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Utiliza el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, MCP de Playwright, Agent Merge y comandos de barra prácticos.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia entre modos de sesión, colabora en lienzos y gestiona las incidencias y las solicitudes de incorporación de cambios de GitHub en la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Utiliza GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
